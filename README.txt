Beyond Blue. — ローカル表示用

【開き方】
ZIPを展開し、index.htmlをダブルクリックしてブラウザで開いてください。
サーバーの起動やソフトのインストールは不要です。
ページを下にスクロールすると、文字の中に青いぼかしが広がります。

【ファイル】
index.html : 文章・レイアウト・スクロール演出（CSS / JavaScriptを含む）
grain.svg  : 青い文字に重ねるノイズ素材
README.txt : この説明

【フォント】
Noto Sans JPをGoogle Fontsから読み込みます。
このフォントの表示にはインターネット接続が必要です。
オフライン時は端末のsans-serifフォントに切り替わります。

【仕様】
中央揃え / 見出し22px / 本文16px / 段落間35px
ベースの青：#0063B1
OSで「視差効果を減らす」等が有効な場合は、全文を最初から表示します。
